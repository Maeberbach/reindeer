# Icon Placeholders for Reindeer FairPlay

Place your custom application icons in this folder before building production installers with `electron-builder`:

- **Windows Icon**: `icon.ico` (256x256 multi-resolution ICO file)
- **macOS Icon**: `icon.icns` (1024x1024 ICNS file)
- **Linux/PNG Fallback**: `icon.png` (512x512 PNG file)

If custom icons are not supplied, `electron-builder` will fallback to standard defaults during build.
